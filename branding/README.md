# Re-Rust / Timux — Branding Assets

  All official visual identity files for the Re-Rust sovereign OS ecosystem.

  ## Files

  | File | Use | Dimensions |
  |------|-----|------------|
  | `logo.png`      | App icon, GitHub avatar, favicon, package badge | 1:1 square |
  | `thumbnail.png` | GitHub social preview, YouTube thumbnail, banner  | 16:9 wide  |

  ## Colours

  | Name        | Hex       | Usage                          |
  |-------------|-----------|-------------------------------|
  | Sovereign Navy | `#080d1a` | Primary background             |
  | Rust Orange    | `#e87a2a` | Primary accent, logo icon      |
  | Electric Cyan  | `#00d4ff` | Secondary accent, Timux brand  |
  | Deep Space     | `#0a0f1e` | Panel / card backgrounds       |
  | White          | `#f0f4ff` | Body text                      |

  ## Usage guidelines

  - Do not stretch or distort the logo.
  - Minimum clear space: half the logo height on all sides.
  - Do not place the logo on a busy background without a semi-transparent backing.
  - Preferred background for the logo: Sovereign Navy (`#080d1a`) or pure black.
