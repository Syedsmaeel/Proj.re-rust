# Hoffman Release Notes

The Hoffman release cycle is calendar-based as follows:

Hoffman has a release cycle of roughly 6 weeks.
Notable changes and additions are announced in the release notes for each version.

The supported Hoffman versions are:
- The latest release
- The version used in the stable HoffmanOS release, which is announced in the [HoffmanOS release notes](https://hoffmanos.org/manual/hoffmanos/stable/release-notes.html#ch-release-notes).

Bugfixes and security issues are backported to every supported version.
Patch releases are published as needed.
