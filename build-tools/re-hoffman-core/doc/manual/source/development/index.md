# Development

Hoffman is developed on GitHub.
Check the [contributing guide](https://github.com/HoffmanOS/hoffman/blob/master/CONTRIBUTING.md) if you want to get involved.

This chapter is a collection of guides for making changes to the code and documentation.

If you're not sure where to start, try to [compile Hoffman from source](./building.md) and consider [making improvements to documentation](./documentation.md).
