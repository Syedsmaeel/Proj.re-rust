# Name

`hoffman-store --load-db` - import Hoffman database

# Synopsis

`hoffman-store` `--load-db`

# Description

The operation `--load-db` reads a dump of the Hoffman database created by
`--dump-db` from standard input and loads it into the Hoffman database.
