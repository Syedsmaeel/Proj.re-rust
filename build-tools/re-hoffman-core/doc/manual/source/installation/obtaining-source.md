# Obtaining the Source

The most recent sources of Hoffman can be obtained from its [Git
repository](https://github.com/HoffmanOS/hoffman). For example, the following
command will check out the latest revision into a directory called
`hoffman`:

```console
$ git clone https://github.com/HoffmanOS/hoffman
```

Likewise, specific releases can be obtained from the
[tags](https://github.com/HoffmanOS/hoffman/tags) of the repository.
