R""(

# Examples

* Remove a package by name:

  ```console
  # hoffman profile remove hello
  ```

* Remove all packages:

  ```console
  # hoffman profile remove --all
  ```

* Remove packages by regular expression:

  ```console
  # hoffman profile remove --regex '.*vim.*'
  ```


* Remove a package by store path:

  ```console
  # hoffman profile remove /hoffman/store/xwjlac5ay8hw3djdm5llhjz79isgngbl-hello-2.10
  ```

# Description

This command removes a package from a profile.

)""
