# Hoffman Script Core

**A Sovereign, Declarative Engine for Timux Fractal Architecture.**

Hoffman Script is a fork of the Nix evaluation engine, rebranded and optimized for the **Timux Sovereign Substrate**. It provides the declarative power required to build complex, fractal operating systems with mathematical precision.

## Key Features
- **Sovereign store**: Capability-gated binary asset management.
- **Fractal evaluation**: Declaratively define nested sub-kernels and their personalities.
- **Hoffman DSL**: A simple yet powerful language for OS construction.

## Fork Information
- **Original Project**: NixOS/nix
- **Rebrand Date**: May 2026
- **Status**: Transitioning to Timux-native syscall shims.
